## Sobre o Projeto

Resolução dos exercícios práticos de algoritmos propostos pela Rocketseat, divididos em 3 seções:

1. **Descrição Narrativa** — 10 exercícios quebrando tarefas do dia a dia em passos lógicos
2. **Fluxograma** — 3 exercícios representados com formas padrão (início/fim, decisão, processo, entrada/saída)
3. **Pseudocódigo** — 10 exercícios com pseudocódigo + implementação funcional em Python

---

## Seção 1 — Descrição Narrativa

Tarefas cotidianas organizadas em sequência lógica de passos:

| # | Tarefa |
|---|--------|
| 1 | Fazer um café coado |
| 2 | Configurar o despertador no celular |
| 3 | Ligar um computador |
| 4 | Carregar o celular |
| 5 | Assistir a um filme em casa |
| 6 | Regar uma planta |
| 7 | Fazer uma pipoca |
| 8 | Participar de uma reunião online |
| 9 | Criar uma lista com as tarefas da semana |
| 10 | Assistir a um vídeo do Diego no canal da Rocketseat |

---

## Seção 2 — Fluxograma

Representação textual dos fluxogramas usando formas padrão:

| Forma | Significado |
|-------|-------------|
| `[INICIO]` / `[FIM]` | Terminal (início/fim) |
| `[ENTRADA]` | Entrada de dados (paralelogramo) |
| `[PROCESSO]` | Processamento (retângulo) |
| `[DECISAO]` | Decisão (losango) |
| `[SAIDA]` | Saída de dados (paralelogramo) |

| # | Exercício |
|---|-----------|
| 1 | Calcular o dobro de um número |
| 2 | Verificar se o número é menor que 10 |
| 3 | Contar até 5 |

---

## Seção 3 — Pseudocódigo

Cada exercício apresenta o pseudocódigo e uma demonstração real executada em Python:

| # | Exercício |
|---|-----------|
| 1 | Imprimir um número em tela |
| 2 | Somar dois números |
| 3 | Contar de 1 até 10 usando loop |
| 4 | Verificar se o número é par ou ímpar |
| 5 | Verificar se número é positivo, negativo ou zero |
| 6 | Calcular média de 3 notas |
| 7 | Verificar se aluno foi aprovado (média >= 5) |
| 8 | Maior entre dois números |
| 9 | Mostrar os múltiplos de 3 até 30 |
| 10 | Contagem regressiva de 10 até 1 |

---

## Como Executar

**Pré-requisito:** Python 3.6+

```bash
python algoritmos.py
```

O programa exibe as 3 seções sequencialmente no terminal: primeiro as descrições narrativas, depois os fluxogramas e por fim os pseudocódigos com suas execuções em Python.
